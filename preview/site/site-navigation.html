When to use a site navigation

Help users find what they need quickly by providing consistent navigation.

Site navigation gives users an overview of a site's content by outlining its main categories. It can also help users find key content.

Site navigation helps users understand that they're using your service and lets them navigate around your service.

Use the site navigation to help users understand that they're using your service.

To decide when to use navigation links in your service, see the Help users to navigate a service pattern.

When not to use a site navigation

If your service is a linear end-to-end journey, you probably do not need navigation links. You can use the Complete multiple tasks pattern.

How to use a site navigation

The main navigation on a website, site navigation is a set of links that appears on every page.

Site navigation arranges key links into a row and should go at the top of a website.

Site navigation displays as an expandable 'menu' button on small devices.

Place links to your most important top-level sections first. When there is not enough space to show all links, they will be moved into the "More" drop-down list.

You can highlight the section the user is currently in.

Accessibility

Do not allow expanded menus to cover focused content. Avoid fixed or sticky elements that obscure the currently focused element or its focus indicator. Keyboard users must be able to see where focus is at all times. This supports WCAG 2.2 Success Criterion 2.4.11 Focus Not Obscured (Minimum), level AA.

Make sure assistive technologies can identify the list of links as a structural roadmap. The element must use a semantic HTML <nav> or a navigation ARIA landmark role to ensure screen readers can announce the block correctly to meet WCAG 2.2 Success Criterion 1.3.1 Info and Relationships, level A.

Source
