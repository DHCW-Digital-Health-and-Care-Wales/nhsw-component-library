Header

The site header uses the NHS Wales blue (#005eb8) as its background. The search button uses the dark navy (#1b365d) to stand out against the blue bar.

With navigation (shown above)

Include a <nav class="nhsw-site-header__nav"> element immediately after the closing </div> of nhsw-site-header__container to add a navigation row below the top bar.

The nav row is automatically hidden on mobile (< 40rem) – use the bottom navigation component instead on small screens.

Mark the active link with nhsw-site-header__nav-link--current and aria-current="page".

Without navigation

Simply omit the <nav> element. The top bar works independently.

Service name

Mobile bottom navigation

On screens narrower than 40rem the header nav bar is hidden. Use nhsw-bottom-nav to provide navigation at the bottom of the viewport instead, following the mobile app pattern.

The bottom nav is always hidden on desktop – it is only ever visible on mobile. Resize your browser window below 640px to see the bar at the bottom of this page.

Preventing content overlap

Add nhsw-has-bottom-nav to <body> when the bottom nav is present. This class adds padding-bottom: 5rem to nhsw-main-wrapper on mobile so page content is never hidden behind the fixed bar.

Active state

Mark the current page link with nhsw-bottom-nav__link--current and aria-current="page".

Icons

Place any inline SVG inside nhsw-bottom-nav__icon. Decorative icons should carry aria-hidden="true". The visible label text in nhsw-bottom-nav__label provides the accessible name.
