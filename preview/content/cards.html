Cards

Use cards to display a summary of content and link users to more detail.

Basic card

A simple card with a title and description.

Card title

Card description text. Use this to summarise the content that the card links to.

<div class="nhsw-card">
  <h3 class="nhsw-card__title">Card title</h3>
  <p class="nhsw-card__description">Card description text.</p>
</div>
{% from "card/macro.njk" import nhswCard %}

{{ nhswCard({
  title: "Card title",
  description: "Card description text."
}) }}

Card with link

Make the card title a link to direct users to the related page.

Find a GP

Search for a GP surgery by name or location to find contact details and opening times.

<div class="nhsw-card">
  <h3 class="nhsw-card__title">
    <a class="nhsw-card__title-link" href="/destination">Card title</a>
  </h3>
  <p class="nhsw-card__description">Card description text.</p>
</div>
{% from "card/macro.njk" import nhswCard %}

{{ nhswCard({
  title: "Card title",
  titleHref: "/destination",
  description: "Card description text."
}) }}

Cards in a grid

Use the grid system to display multiple cards in a row. Cards are equal height within a row.

Book an appointment

Book, change or cancel a GP, hospital or other health appointment online.

Order a repeat prescription

Request repeat prescriptions from your GP and see your medication history.

View your health record

Access your GP health record, including allergies, medications and test results.
