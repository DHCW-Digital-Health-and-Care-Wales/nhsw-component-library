Pagination

Help users navigate forwards and backwards through a series of pages.

Content page pagination

Use content page pagination to let users navigate between related pages, such as sections of a guide.

  • Previous Treatments
  • Next Symptoms 
<nav class="nhsw-pagination" role="navigation" aria-label="Pagination">
  <ul class="nhsw-pagination__list">
    <li class="nhsw-pagination-item--previous">
      <a class="nhsw-pagination__link" href="/previous-page">
        <svg class="nhsw-icon" ...></svg>
        <span class="nhsw-pagination__title">Previous</span>
        <span class="nhsw-pagination__page">Treatments</span>
      </a>
    </li>
    <li class="nhsw-pagination-item--next">
      <a class="nhsw-pagination__link" href="/next-page">
        <svg class="nhsw-icon" ...></svg>
        <span class="nhsw-pagination__title">Next</span>
        <span class="nhsw-pagination__page">Symptoms</span>
      </a>
    </li>
  </ul>
</nav>

Numbered pagination

Use numbered pagination when showing search results or lists split across multiple pages.

Previous
  • 1
  • 2
  • 3
  • 4
  • 5
Next 
<nav class="nhsw-pagination nhsw-pagination--numbered" role="navigation" aria-label="Pagination">
  <a href="/previous" class="nhsw-pagination__previous" rel="prev">
    <svg class="nhsw-pagination__icon" ...></svg>
    <span class="nhsw-pagination__title">Previous</span>
  </a>
  <ul class="nhsw-pagination__list">
    <li class="nhsw-pagination__item">
      <a class="nhsw-pagination__number-link" href="/page/1" aria-label="Page 1">1</a>
    </li>
    <li class="nhsw-pagination__item nhsw-pagination__item--current">
      <a class="nhsw-pagination__number-link" href="/page/2" aria-current="page" aria-label="Page 2">2</a>
    </li>
    <li class="nhsw-pagination__item">
      <a class="nhsw-pagination__number-link" href="/page/3" aria-label="Page 3">3</a>
    </li>
  </ul>
  <a href="/next" class="nhsw-pagination__next" rel="next">
    <span class="nhsw-pagination__title">Next</span>
    <svg class="nhsw-pagination__icon" ...></svg>
  </a>
</nav>
{% from "pagination/macro.njk" import nhswPagination %}

{{ nhswPagination({
  variant: "numbered",
  previous: { href: "/page/2" },
  next: { href: "/page/4" },
  items: [
    { number: 1, href: "/page/1" },
    { number: 2, href: "/page/2" },
    { number: 3, href: "/page/3", current: true },
    { number: 4, href: "/page/4" },
    { number: 5, href: "/page/5" }
  ]
}) }}
