Manual test scenarios
Given a pagination component. When a previous, next, or numbered link is selected. Then it takes you to exactly the right page.
Given the numbered pagination variant. Then the current page is visually distinct. And a screen reader announces it as the current page, not just another link.
Given a numbered pagination with an ellipsis. When a screen reader reads it. Then the ellipsis isn't announced as a clickable link.
Given a pagination component. When a screen reader user navigates by landmarks or headings. Then they can identify it as the page navigation.
Given the next-only pagination variant. Then a user can move forward through content without any numbered list showing.
