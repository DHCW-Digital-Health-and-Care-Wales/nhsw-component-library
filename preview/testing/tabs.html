Manual test scenarios
Given a set of tabs. When a different tab is clicked. Then only that tab's panel is shown, and the others are hidden.
Given a tab is focused via keyboard. When the right or left arrow key is pressed repeatedly. Then focus moves to each tab in turn and wraps back around at the start/end.
Given a set of tabs. When a screen reader user focuses one. Then they hear its name, its position (e.g. "2 of 4"), and whether it's selected.
Given a set of tabs with realistic label lengths. Then the row of tabs stays on a single line at normal viewport widths.
Given a set of tabs. Then none of them are greyed out or disabled.
