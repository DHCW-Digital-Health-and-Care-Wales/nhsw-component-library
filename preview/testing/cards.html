Manual test scenarios
Given a clickable card. When anywhere within the card is clicked. Then it takes you to the card's destination.
Given a non-clickable card. When a screen reader reads it. Then it isn't announced as a link.
Given a grid of cards. When viewed on a mobile-width screen. Then they stack into a single column without overlapping or clipped text.
Given a card using the small icon-badge variant. When a screen reader reads the card. Then the icon glyph itself isn't read out as text.
Given cards grouped together for navigation. When a screen reader reads them. Then they're announced as a list of options, not as unrelated content.
Given a card with its heading level overridden (e.g. h3 instead of h2). Then the rendered heading tag matches what was specified, keeping the page outline correct.
