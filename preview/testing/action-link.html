Manual test scenarios
Given an action link. Then a blue circular arrow icon sits immediately before the text. And there is a clear gap between the icon and the text, not crammed together.
Given an action link in its default state. Then the icon and the text are the same link-blue colour.
Given an action link. When you hover over it with a mouse. Then the text changes colour. And the icon stays link-blue.
Given an action link in its default state. Then the text is clearly readable against the white page background.
Given an action link placed on a dark/navy background. Then both the icon and the text remain clearly visible.
Given an action link with a decorative icon. When a screen reader reads it out. Then only the link text is announced, with no extra description of the icon.
