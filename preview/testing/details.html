Manual test scenarios
Given a details component. When the summary line is clicked. Then the hidden content shows or hides accordingly.
Given a page with several details components. When one is opened. Then the others stay in whatever state they were in.
Given a details component set to start open. Then its content is visible as soon as the page loads, with no interaction needed.
Given a details component. Then its background gives clear contrast against the page.
Given the summary link text. Then it clearly describes what you'll find inside, rather than something vague like "More information".
