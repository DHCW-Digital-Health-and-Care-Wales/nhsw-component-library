Manual test scenarios
Given a nav link pointing at the current page. Then it's visually distinguished from the other links. And a screen reader announces it as the current page.
Given a navigation with an expandable menu. When a submenu is open. Then it doesn't cover the element that currently has keyboard focus.
Given the dark-background navigation variant. Then the links remain clearly readable.
Given a nav item with a tag next to it. Then the tag sits correctly alongside the link without reducing the link's clickable area.
