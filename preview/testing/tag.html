Manual test scenarios
Given each of the 10 tag colours. Then the text is clearly readable against its background.
Given a status tag, e.g. "Complete" in green or "Overdue" in red. Then the text label alone tells you the status, without needing to know what the colour means.
Given a two-part tag. When a screen reader reads it. Then both parts are announced in a way that makes sense together.
Given a tag placed inside a summary list row. Then it stays aligned correctly and doesn't break the row's layout.
Given a UI that lets users reorder tags. Then there's a way to do it other than dragging, e.g. buttons or keyboard controls.
