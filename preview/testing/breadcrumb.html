Manual test scenarios
Given a user is on a nested page. Then the breadcrumb lists each parent page in order, ending at or just before the current page.
Given a breadcrumb with several links. When a link partway through the trail is selected. Then it lands on exactly that page.
Given a breadcrumb trail. Then there is enough space between links that you can't easily tap the wrong one.
Given the dark-background variant of the breadcrumb. Then the text remains clearly visible against the dark background.
Given a breadcrumb trail. When a screen reader reads it out. Then each link is announced by its page name, not just "link, link, link".
