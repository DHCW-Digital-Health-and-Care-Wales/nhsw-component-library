Manual test scenarios
Given a select field. When a user opens it and chooses an option using only the keyboard. Then it works without needing a mouse.
Given a select with many options, e.g. "Choose Pharmacy". Then a user can find and pick the right option without excessive difficulty.
Given the s/m/l select size variants. Then each is a clearly different, sensible width for its content.
