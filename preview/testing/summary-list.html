Manual test scenarios
Given a summary list row with a Change link. Then it's large enough, or has enough space around it, to tap without missing.
Given a user selects "Change" against a previously answered question. Then the field is pre-filled with what they entered before. And this doesn't apply if the answer is no longer valid or restoring it would be unsafe.
Given a summary list row, e.g. "Name: Karen Francis". When a screen reader reads it. Then the label and value are announced together, clearly associated.
Given several summary cards grouped on one page. Then a user can clearly tell them apart and move between them.
