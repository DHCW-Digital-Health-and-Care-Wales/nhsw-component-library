Manual test scenarios
Given a textarea. When a user clicks into it and types multiple lines. Then the text wraps and appears as expected.
Given a textarea. When a user pastes text into it. Then the pasted text appears correctly — paste is never blocked.
Given a textarea with a character limit and live counter. When a user types past the limit. Then the counter keeps counting (going negative) without breaking or freezing.
Given the sized textarea variant. Then its visible height roughly matches how much someone is expected to write.
