Manual test scenarios
Given a notification banner (default or success). Then it has a text heading ("Important"/"Success") as well as its colour treatment.
Given a success banner appears after an action, e.g. a form submission. Then a screen reader announces it without the user needing to go and find it.
Given a notification banner containing a link. When the link is selected. Then it's visually distinct from the surrounding text and navigates correctly.
Given this banner type appears on more than one page. Then it uses the same heading text each time, so users learn to recognise it.
