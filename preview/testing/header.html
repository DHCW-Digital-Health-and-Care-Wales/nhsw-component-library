Manual test scenarios
Given the header's search field. Then it has a visible or properly linked label, not just placeholder text.
Given the header variant without a search bar. Then the remaining elements are positioned without an awkward gap.
Given the mobile bottom navigation variant. When viewed on a small screen. Then it stays visible and tappable without overlapping page content.
Given the header on a mobile-width screen. When any nav toggle is used via keyboard. Then it opens/closes correctly and focus is never trapped inside it.
