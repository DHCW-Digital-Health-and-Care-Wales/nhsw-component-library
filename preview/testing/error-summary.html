Manual test scenarios
Given a form submitted with invalid answers. Then an error summary appears with a heading and a list of what's wrong.
Given the error summary's list of links. When one is selected. Then focus moves straight to the matching field on the page.
Given a user has filled in some fields and left others invalid. When they submit the form. Then everything they already typed is still there.
Given a form submission produces validation errors. When the page reloads with the error summary showing. Then keyboard focus moves to the error summary heading without the user needing to scroll up and find it.
