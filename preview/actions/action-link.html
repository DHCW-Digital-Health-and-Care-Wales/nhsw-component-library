Overview

When not to use action links

Do not use action links in forms. Use a button instead.

We don't use action links just to link to another page or site. If you need a link to stand out, you can use inset text.

Source

Learn more on the Action link in NHS England Design System.

Follow discussions about Action Link on NHS England GitHub to see the latest updates and resolved issues.

Action link variants: how to use

Action link variants: how to use

Keep the words on the action link short. Start with a verb, for example: "Book an appointment" or "Apply for an EHIC card".

Action links usually sit in a block of text. You can also put one in a care card. (Find out more about helping users decide when and where to get care, with care cards.)

You can have more than one action link on a page but avoid putting them near each other.

The link colour and background colour contrast ratio is 5.76:1, which passes AAA guidelines at that font size.

Make sure all users can see the action link. The background colour must have a contrast ratio of at least 4.5:1 with white to meet WCAG 2.2 success criterion 1.4.3 Contrast (minimum), level AA (W3C).

Colour variants

Action links also have 4 colour variants for use on light backgrounds. Choose a variant based on the context the link sits in, not to add visual variety to a page.

Default (green)

Use the default green action link to signpost the start of a digital service, such as starting an application or checking a symptom.

Use the red variant sparingly, only where the destination itself carries urgency or risk, such as an emergency or safeguarding service. Do not use red simply to make a link stand out.

Accessibility

Accessibility

Action links are built from a native <a> element, so they are keyboard focusable and operable with assistive technology without any extra scripting.

Icon

The arrow icon is decorative. It must always carry aria-hidden="true" and focusable="false" so screen readers announce only the link text, never the SVG.

Colour

Colour is never the only way an action link is identified — the bold text label and underline-on-hover carry the same meaning in every variant. All variant colours meet WCAG AA contrast against a white background.

Focus state

On keyboard focus, the action link shows the standard yellow focus indicator with a dark focus text colour, matching the focus style used across the rest of the design system.

Visited links

Visited action links keep the same text colour as unvisited ones, so the bold label and icon remain easy to read once a user has already followed the link.
