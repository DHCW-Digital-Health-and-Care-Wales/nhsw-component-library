Action link

Use action links to help users get to the next stage of a process quickly, by signposting the start of a digital service or providing a link to a form.

Default action link

Action links use a green circle arrow icon to make them stand out from standard text links.

Find a GP

Multiple action links

You can stack multiple action links together to present a set of related actions.

Book a vaccination appointment Check your symptoms Find your nearest pharmacy

Colour variants

Use colour variants to differentiate action links by context or urgency.

Blue

View your medical records

Navy

Submit your application

Red

Report an urgent safety concern
