How to use buttons

We have 5 types of buttons:

  • primary buttons
  • secondary buttons
  • exception buttons
  • warning buttons
  • button styled as a link

Align the primary action button to the left edge of your form. On smaller screens, such as on mobile, buttons stretch across the screen's width.

Primary buttons

When to use a primary button

Use a primary button for the main call to action on a page, for example to help users start an application or save their progress. Use only 1 primary button on a page.

Secondary buttons

When to use a secondary button

Use a secondary button for secondary actions on a page or when an action needs less prominence.

{% capture html_sample %}{% raw %}<button class="nhsw-button nhsw-button--secondary">Find address</button>{% endraw %}{% endcapture %} {% capture njk_sample %}{% raw %}{% from "button/macro.njk" import nhswButton %} {{ nhswButton({ text: "Find address", classes: "nhsw-button--secondary" }) }}{% endraw %}{% endcapture %} {% include code-viewer.html id="button-secondary" html=html_sample njk=njk_sample %}

Warning buttons

Warning buttons are designed to make users think carefully before they use them. Only use them for actions with serious destructive consequences.

Accessibility

Buttons must have a visible label and must not rely on colour alone to communicate their purpose. Ensure sufficient colour contrast between button background and text.
