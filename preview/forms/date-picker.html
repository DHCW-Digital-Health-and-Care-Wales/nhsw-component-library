When to use a date picker

Use a date picker when users need to select a date they may not know off the top of their head, such as an appointment or a deadline. For memorable dates like a date of birth, use the date input component instead.

Keyboard controls

  • Arrow keys — move focus between days
  • Home / End — first or last day of the current week
  • Page Up / Down — previous or next month
  • Shift + Page Up / Down — previous or next year
  • Enter — confirm the focused day
  • Escape — close without selecting

Available data attributes

  • data-input-id — sets the id and name on the generated input (required)
  • data-input-name — overrides the name if it differs from the id
  • data-value — pre-populates the input in DD-MMM-YYYY format
  • data-disabled — presence of this attribute renders the input and toggle disabled
  • data-describedby — forwarded as aria-describedby on the generated input

Usage

Include nhsw.css for styles, then add the script before the closing </body> tag. All elements with data-module="nhsw-date-picker" are initialised automatically. For dynamically inserted content, call NhswDatePicker.initAll(containerEl).

<script src="dist/nhsw-date-picker.js"></script>
