Radios

Use radios when users can only select one option from a list.

Standard radios

Use radios when you want users to select a single answer from a list of options.

Have you changed your name?
This includes a change of name by deed poll.

Inline radios

Use inline radios when there are only 2 options to choose from, such as yes or no.

Have you changed your name?

Radios with hints

You can add hints to radio items to provide additional information about the options.

How do you want to be contacted?
Select one option.
We will send you a confirmation email.
We will call you between 9am and 5pm.
We will text you a confirmation code.

Radios with a divider

If one or more options is different from the others, you can separate them using a divider such as "or".

Where do you live?
or

Conditional radios (reveal)

You can reveal additional questions when a user selects a particular radio option.

How would you prefer to be contacted?
Select one option.

Error state

Radio groups use the form group error pattern with a red left border and an error message.

Have you changed your name?

 Error: Select yes if you have changed your name
