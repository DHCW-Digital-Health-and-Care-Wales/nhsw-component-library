Text input with prefix and suffix

Use prefixes and suffixes to help users enter things like currencies and measurements. Do not rely on them alone because screen readers will not read them out. Make sure the label or hint text includes the unit.

Input with prefix

Use a prefix for units that come before the value, such as a currency symbol.

Enter the amount in pounds.
£

Input with suffix

Use a suffix for units that come after the value, such as a weight or measurement.

kg
