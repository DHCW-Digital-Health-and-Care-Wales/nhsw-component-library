# nhsw-component-library
HTML/CSS Styling library used for consistent look &amp; feel of DHCW apps. (Currently in development)

## GitHub Pages

This repository is configured to deploy a static site from the `/docs` folder using GitHub Actions.

### How to publish your files

1. Add or replace files inside `/docs` (for example `index.html`, CSS, JS, assets).
2. Commit and push to the default branch.
3. In GitHub repository settings, set **Pages** source to **GitHub Actions** (one-time setup).

After deployment, your site will be available at:
`https://dhcw-digital-health-and-care-wales.github.io/nhsw-component-library/`
