Select

When to use select

Use select to let users choose an option from a long list. The select component should only be used as a last resort in public-facing services because research shows that some users find selects very difficult to use.

When not to use select

Before using the select component, try asking users other questions which will allow you to present them with fewer options. Consider using radios instead.
