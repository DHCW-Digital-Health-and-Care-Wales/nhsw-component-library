Usage rules

When to use the text input component

Use text input to let users enter a single line of text, such as their name or phone number.

When not to use the text input component

Do not use this component if you need users to enter longer answers that might span several lines. In this case, use the textarea component.

Labels

Give each text input a visible label. Do not use placeholder text for a label as it disappears when users click into the input.

Align labels above the text inputs they refer to. Labels should be short, direct and written in sentence case. Do not use colons at the end of labels.

One question per page

If you are asking just 1 question per page, you can set the contents of the <label> as the page heading. This helps screen reader users hear the question once.

More than one question per page

If you're asking more than 1 question on the page, do not set the contents of the <label> as the page heading.

Make text inputs the right size

Help users understand what they should enter by making text inputs the right size for the information you want them to give you.

Fluid width inputs

Fluid width inputs resize with the viewport and are useful when sizing an input in relation to its parent container.

Fixed width inputs

Use fixed width inputs for content that has a specific, known length. For example, postcode inputs should be postcode-sized.

Using hint text

You can use hint text to give users help in context, so they understand what they need to enter.

It is on your National Insurance card, benefit letter, payslip or P60.

Asking for numbers

Whole numbers

If you're asking the user to enter a whole number, set the inputmode attribute to numeric.

Decimal numbers

Decimal numbers should be labelled clearly so users know what format is expected.

For example, 12.50

Prefixes and suffixes

Use prefixes and suffixes to help users enter things like currencies and measurements. Do not rely on them alone because screen readers will not read them out.

Enter the amount in pounds.

Position prefixes and suffixes outside of their input, and allow for users entering the prefix or suffix themselves during validation.

States

Enter a valid value

Do not disable copy and paste

Users often need to copy and paste information into a text input, so do not stop them doing this.
