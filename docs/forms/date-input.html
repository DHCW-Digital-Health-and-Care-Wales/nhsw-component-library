Date input

When to use date input

Use date input to help users enter a memorable date, like their date of birth.

Use date input when you�re asking users for a date they already know.

When not to use date input

Do not use date input if users are unlikely to know the exact date you're asking about.

How to use date input

Date input consists of 3 fields to let users enter a day, month and year.

Group the 3 date fields together in a <fieldset> with a <legend> that describes them.

Never automatically tab users between the fields.

Autocomplete for date of birth

When asking for a date of birth, use autocomplete="bday-day", autocomplete="bday-month" and autocomplete="bday-year".
