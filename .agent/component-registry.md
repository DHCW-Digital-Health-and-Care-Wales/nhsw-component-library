# NHSW Components

## nhsw-input
Single-line text input.

Supports:
- nhsw-input--full
- nhsw-input--half
- nhsw-input--width-10
- nhsw-is-invalid

Requires:
- nhsw-label
- nhsw-form-group

## nhsw-select
Dropdown select component.

Supports:
- nhsw-select--s
- nhsw-select--m
- nhsw-select--l

## nhsw-date-input
Three-field date component.

Requires:
- fieldset
- legend
- nhsw-form-group

## nhsw-radios
Radio button group for single-selection lists.

Supports:
- nhsw-radios--inline
- nhsw-radios__hint
- nhsw-radios__divider
- nhsw-radios__conditional
- nhsw-radios__conditional--hidden

Requires:
- nhsw-fieldset
- nhsw-form-group
- nhsw-label

## nhsw-checkboxes
Checkbox group for multi-selection lists.

Supports:
- nhsw-checkboxes__hint
- nhsw-checkboxes__divider
- nhsw-checkboxes__conditional
- nhsw-checkboxes__conditional--hidden

Requires:
- nhsw-fieldset
- nhsw-form-group
- nhsw-label

## nhsw-summary-list
Key-value summary using a definition list.

Supports:
- nhsw-summary-list--no-border
- nhsw-summary-list__row--no-border
- nhsw-summary-list__actions

## nhsw-tag
Status indicator tag.

Supports:
- nhsw-tag--white
- nhsw-tag--grey
- nhsw-tag--green
- nhsw-tag--aqua-green
- nhsw-tag--blue
- nhsw-tag--purple
- nhsw-tag--pink
- nhsw-tag--red
- nhsw-tag--orange
- nhsw-tag--yellow

## nhsw-action-link
Prominent link with green circle arrow icon for signposting services.

Supports:
- nhsw-action-link__icon
- nhsw-action-link__text
- nhsw-action-link--blue
- nhsw-action-link--navy
- nhsw-action-link--red

## nhsw-details
Native HTML details/summary disclosure component.

Supports:
- nhsw-details__summary
- nhsw-details__summary-text
- nhsw-details__text
- open attribute

## nhsw-pagination
Numbered page navigation with previous/next and ellipsis.

Supports:
- nhsw-pagination__previous
- nhsw-pagination__next
- nhsw-pagination__list
- nhsw-pagination__item--current
- nhsw-pagination__item--ellipsis

## nhsw-table
Data table with caption, row headers and numeric alignment.

Supports:
- nhsw-table__caption (--s, --m, --l, --xl)
- nhsw-table__header--numeric
- nhsw-table__cell--numeric
- nhsw-table-responsive
- nhsw-table-responsive__heading

## nhsw-notification-banner
Notification banner with default and success variants.

Supports:
- nhsw-notification-banner--success
- nhsw-notification-banner__header
- nhsw-notification-banner__title
- nhsw-notification-banner__content
- nhsw-notification-banner__heading
- nhsw-notification-banner__link

## nhsw-input-wrapper
Prefix and suffix wrapper for text inputs.

Supports:
- nhsw-input-wrapper__prefix
- nhsw-input-wrapper__suffix

Requires:
- nhsw-input
- nhsw-form-group
- nhsw-label
