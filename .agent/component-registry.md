# NHSW Components

## nhsw-input
Single-line text input.

Supports:
- nhsw-input--full
- nhsw-input--half
- nhsw-input--width-10
- nhsw-is-invalid

Requires:
- nhsw-label
- nhsw-form-group

## nhsw-select
Dropdown select component.

Supports:
- nhsw-select--s
- nhsw-select--m
- nhsw-select--l

## nhsw-date-input
Three-field date component.

Requires:
- fieldset
- legend
- nhsw-form-group
